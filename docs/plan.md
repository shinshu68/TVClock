# TVClock 開発方針

## 目的・背景
Windows のデスクトップのタスクバーにある時計は文字が小さく、作業中に時刻をひと目で確認しづらい。常に最前面に表示され、読みやすい大きさで時刻を出す時計アプリを作り、時刻確認の手間をなくす。

見た目のイメージは、テレビなどに表示されるデジタルの時刻表示。

利用者は自分自身（個人利用）。

## スコープ

### やること
- 時:分 の表示（秒・日付・曜日は表示しない）。書式は 24 時間表記の `HH:mm`（例：`09:05`）
- 常に最前面に表示する
- ドラッグでウィンドウを移動し、次回起動時に同じ位置で表示する
- 背景の半透明化（透明度の変更）
- 文字サイズの変更
- クリックスルー（時計の上をクリックしても下のウィンドウを操作できる）
- Windows 起動時の自動起動（オン／オフ切り替え）

### やらないこと
- 秒・日付・曜日の表示
- 7セグメント風の表示（専用フォントや独自描画は使わない）
- アラーム、タイマー、ストップウォッチなど時計以外の機能
- Windows 以外の OS への対応

## 技術選定
- **C# + WPF（.NET 10）**
  - Windows ネイティブで動作が軽く、常駐アプリに向く
  - .NET 10 は長期サポート（LTS）版で、サポート期限は 2028年11月14日。.NET 8 も LTS だが 2026年11月10日にサポートが終了するため、長く常駐させて使うアプリとして .NET 10 を選ぶ
  - `Topmost` プロパティで最前面表示ができ、枠なし・透過ウィンドウ（`WindowStyle=None`、`AllowsTransparency`）も標準機能で作れる
  - 単一の exe として配布できる

## ディレクトリ構成
- `TVClock.slnx`：ソリューションファイル（リポジトリのルートに置く）
- `src/TVClock/`：WPF プロジェクト（アプリ本体）。プロジェクトが増えた場合に `src/` の下へ並べられるよう、プロジェクトごとにフォルダを分ける
- `tests/`：単体テストのプロジェクトを置く。テストフレームワークは xUnit（.NET の OSS で広く使われており、情報や実例が多いため）

## 設計方針
- ウィンドウは枠なし・透過背景とし、時刻の文字と半透明の背景だけを描画する
- 時刻の更新はタイマー（`DispatcherTimer`）で行う。表示は分単位だが、分の切り替わりが遅れないよう短い間隔で確認する（間隔は実装時に決める）
- 設定はユーザーごとの領域の `%APPDATA%\TVClock\settings.json` に JSON で保存し、起動時に読み込む。保存する項目は位置・文字サイズ・透明度・クリックスルーの状態・自動起動の状態。ファイルがない・壊れている場合は、既定の設定で起動する
- 設定の変更は、時計の右クリックメニューから開く設定画面で行う。右クリックメニューには「設定」と「終了」を置く。設定画面での変更はその場で時計に反映し、設定画面を閉じたときに保存する
- 文字サイズの既定値は 96、範囲は 24〜300（設定画面では 12 刻み）。背景の不透明度の既定値は 0%（背景なし）、範囲は 0〜100%（設定画面では 10% 刻み）。透過させるのは背景だけで、文字は透過させない
- 設定ファイルの文字サイズ・背景の不透明度が範囲外のときは範囲内に丸め、数値として不正なときは既定値で表示する
- 保存した位置が全モニターを合わせた領域（仮想スクリーン）の外にある場合は、初回起動時の位置に戻す。モニター単位の厳密な判定（大きさの違うモニターを並べたときの隙間など）は行わない
- クリックスルーは Win32 API の拡張ウィンドウスタイル（`WS_EX_TRANSPARENT` / `WS_EX_LAYERED`）で実現する。P/Invoke は専用のクラスにまとめる
- クリックスルー中はドラッグ移動や右クリックができなくなるため、ウィンドウ以外の操作手段で解除できるようにする（手段は未決事項を参照）
- 自動起動はレジストリの `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` に登録する方式を案とする（スタートアップフォルダにショートカットを置く方式もある）

## 進め方
1. 枠なし・最前面で時:分 を表示する最小構成を作る
2. ドラッグ移動と位置の保存・復元
3. 背景の半透明化と文字サイズの変更（設定の保存を含む）
4. クリックスルーと、その解除手段
5. 自動起動の切り替え
6. 配布用 exe の作成

## 未決事項
- クリックスルー中に解除する手段（タスクトレイアイコン、グローバルホットキーなど）。WPF 単体にはタスクトレイ機能がないため、Windows Forms の `NotifyIcon` を併用するか、NuGet パッケージを追加するかもあわせて決める
- 文字色（既定値と、変更できるようにするか）
- 使用するフォント（Windows にインストール済みのフォントの中から候補を選ぶ予定）
- フルスクリーンのアプリ（動画・ゲームなど）の上にも表示するか
- 配布形態（.NET ランタイムを同梱する self-contained にするか）
