# TVClock 開発方針

## 目的・背景
Windows のデスクトップのタスクバーにある時計は文字が小さく、作業中に時刻をひと目で確認しづらい。常に最前面に表示され、読みやすい大きさで時刻を出す時計アプリを作り、時刻確認の手間をなくす。

見た目のイメージは、テレビなどに表示されるデジタルの時刻表示。

利用者は自分自身 (個人利用)。

## スコープ

### やること
- 時:分 の表示 (秒・日付・曜日は表示しない)。書式は 24 時間表記の `HH:mm` (例：`09:05`)
- 常に最前面に表示する
- ドラッグでウィンドウを移動し、次回起動時に同じ位置で表示する
- 背景の半透明化 (透明度の変更)
- 文字サイズの変更
- 文字の縁取り (太さの変更)
- クリックスルー (時計の上をクリックしても下のウィンドウを操作できる)
- Windows 起動時の自動起動 (オン／オフ切り替え)

### やらないこと
- 秒・日付・曜日の表示
- 7セグメント風の表示 (専用フォントや独自描画は使わない)
- アラーム、タイマー、ストップウォッチなど時計以外の機能
- Windows 以外の OS への対応

## 技術選定
- **C# + WPF (.NET 10)**
  - Windows ネイティブで動作が軽く、常駐アプリに向く
  - .NET 10 は長期サポート (LTS) 版で、サポート期限は 2028年11月14日。.NET 8 も LTS だが 2026年11月10日にサポートが終了するため、長く常駐させて使うアプリとして .NET 10 を選ぶ
  - `Topmost` プロパティで最前面表示ができ、枠なし・透過ウィンドウ (`WindowStyle=None`、`AllowsTransparency`) も標準機能で作れる
  - 単一の exe として配布できる
- **配布形態**：.NET ランタイムを同梱しない (framework-dependent) 単一の exe (win-x64)
  - exe は約 0.2 MB で済む。ランタイムを同梱すると約 173 MB (圧縮しても約 75 MB) になる
  - 利用者は自分だけで、使う PC には .NET 10 デスクトップ ランタイムが入っている。ランタイムの更新 (セキュリティ修正) も、exe を作り直さずに Windows 側の更新で受けられる
  - exe は `%LOCALAPPDATA%\Programs\TVClock\` に置いて使う (ユーザーごとのアプリの置き場所で、管理者権限なしで書き込める)。自動起動にもこの場所の exe を登録する
  - 動かす PC には .NET 10 デスクトップ ランタイム (x64) が必要。入っていない PC で使う場合は、ランタイムを入れるか、同梱する形に切り替える

## ディレクトリ構成
- `TVClock.slnx`：ソリューションファイル (リポジトリのルートに置く)
- `src/TVClock/`：WPF プロジェクト (アプリ本体)。プロジェクトが増えた場合に `src/` の下へ並べられるよう、プロジェクトごとにフォルダを分ける
- `tools/`：開発用のスクリプトを置く (アイコンの画像を作り直すスクリプトなど)
- `tests/`：単体テストのプロジェクトを置く。テストフレームワークは xUnit (.NET の OSS で広く使われており、情報や実例が多いため)

## 設計方針
- ウィンドウは枠なし・透過背景とし、時刻の文字と半透明の背景だけを描画する
- 文字は白、太さは標準で、フォントは指定せず Windows の既定の画面用フォント (日本語環境では Yu Gothic UI) を使う。文字色とフォントを変更する機能は付けない
- 明るい背景の上でも読めるよう、文字の輪郭の外側に黒い縁取りを付ける。`TextBlock` には縁取りがないため、文字を図形にして、縁の線と文字の中を描き分ける。縁の色は黒で固定し、太さだけを設定画面で変えられる
- 背景は余白も角の丸みも付けず、数字と縁にぴったり合わせた長方形にする。フォントが数字の上下左右に確保するすき間は、数字が描かれる範囲を測って詰め、縁の太さの分だけ広げる
- 時刻の更新はタイマー (`DispatcherTimer`) で行う。表示は分単位だが、分の切り替わりが遅れないよう短い間隔で確認する (間隔は実装時に決める)
- 設定はユーザーごとの領域の `%APPDATA%\TVClock\settings.json` に JSON で保存し、起動時に読み込む。保存する項目は位置・文字サイズ・透明度・縁取りの太さ・クリックスルーの状態。ファイルがない・壊れている場合は、既定の設定で起動する
- ほかのプロセスが開いているなどで設定ファイルを読めないときは、0.2 秒ごとに最大 5 回読み直す。それでも読めなければ既定の設定で起動し、保存のときに読み直して、そのセッションで変えた項目だけを保存済みの設定に上書きする。読めないうちは上書きしない (保存済みの設定を既定値で消さないため)
- 保存は一時ファイル (`settings.json.tmp`) に書き終えてから `settings.json` と置き換える (書き込みの途中で終了しても、ファイルが壊れないようにするため)
- 設定の変更は、時計の右クリックメニューから開く設定画面で行う。右クリックメニューには「設定」と「終了」を置く。設定画面での変更はその場で時計に反映し、設定画面を閉じたときに保存する
- 設定画面は時計を Owner にしない普通のウィンドウとし、タスクバーに出す。Owner にすると、最前面の時計に合わせて設定画面も最前面になり、全画面表示のアプリの上に残るため。時計を終了するときは、開いている設定画面も閉じる
- 文字サイズの既定値は 96、範囲は 24〜300 (設定画面では 1 刻み。スライダーの溝のクリックや PageUp / PageDown では 12 ずつ動く)。背景の不透明度の既定値は 0% (背景なし)、範囲は 0〜100% (設定画面では 10% 刻み)。透過させるのは背景だけで、文字は透過させない。縁取りの太さの既定値は 2px、範囲は 0〜5px (設定画面では 1px 刻み。0px は縁取りなし)
- 設定ファイルの文字サイズ・背景の不透明度・縁取りの太さが範囲外のときは範囲内に丸め、数値として不正なときは既定値で表示する
- 保存した位置が全モニターを合わせた領域 (仮想スクリーン) の外にある場合は、初回起動時の位置に戻す。モニター単位の厳密な判定 (大きさの違うモニターを並べたときの隙間など) は行わない
- 時計と同じモニターで、ほかのアプリが全画面表示で手前にある間 (動画・ゲームなど) は、時計を自動で隠す。全画面表示が終わるか、ほかのウィンドウを手前にすると再び表示する。判定は 1 秒ごとに行い、手前のウィンドウがモニター全体を覆っていて、タイトルバーがなく、ツールウィンドウ (`WS_EX_TOOLWINDOW`) でなければ全画面表示とみなす。タスクビューや GeForce Overlay のような画面全体のオーバーレイはツールウィンドウなので、全画面表示とはみなさない
- クリックスルーは Win32 API の拡張ウィンドウスタイル (`WS_EX_TRANSPARENT` / `WS_EX_LAYERED`) で実現する。P/Invoke は専用のクラスにまとめる
- クリックスルー中はドラッグ移動や右クリックができなくなるため、タスクトレイのアイコンのメニューから解除できるようにする。トレイのメニューには「クリックスルー」「設定」「終了」を置き、時計の右クリックメニューにも同じ項目を置く
- 時計はタスクバーにも Alt+Tab の切り替えの一覧にも出さない。操作と終了は、時計の右クリックメニューかタスクトレイのメニューから行う
- タスクトレイのアイコンは Windows Forms の `NotifyIcon` で作る (WPF 単体にはタスクトレイ機能がないため。NuGet パッケージは追加しない)。アイコンはアンテナと脚の付いたテレビの形で、exe のアイコンにも同じものを使う。タスクトレイの小ささでも形が分かるよう、画面には何も描かず、アンテナと脚を大きくしている。画像は `tools/New-AppIcon.ps1` で描いて作り直せる
- クリックスルーの状態は保存し、次回起動時に復元する
- 自動起動は、レジストリの `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` に exe のパスを登録して実現する。切り替えは、時計の右クリックメニューとタスクトレイのメニューの「Windows の起動時に実行」で行う
- 自動起動の状態は設定ファイルには持たず、レジストリの登録から判断する (二重に持つと食い違うため)。登録があり、登録されたパスに exe があればオンとみなす。登録されるのは、切り替えた時点で動いている exe のパス
- 登録されたパスが今の exe と同じかどうかは比べない。比べると、開発用の exe で起動したときにオフと表示され、そこでオンにすると常用の exe の登録を開発用のパスで上書きしてしまうため。exe を別の場所へ移すと、移す前のパスには exe がないのでオフと表示される。オンにし直すと、移した先のパスで登録し直される
- 時計は同じユーザーのセッションで 1 つだけ動かす。すでに起動しているときは、2 つ目の起動は何も表示せずに終了する。起動中かどうかは名前付きの Mutex で判定する。同じ名前の別の種類のオブジェクトがあって Mutex を作れないときは、起動中ではないとみなして起動する (起動中とみなすと、時計が一度も出なくなるため)

## 進め方
1. 枠なし・最前面で時:分 を表示する最小構成を作る
2. ドラッグ移動と位置の保存・復元
3. 背景の半透明化と文字サイズの変更 (設定の保存を含む)
4. クリックスルーと、その解除手段
5. 自動起動の切り替え
6. 配布用 exe の作成
